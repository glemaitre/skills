# `journal/`

`JOURNAL.md` is the index (Status, Data understanding, History,
Ideas, Backlog). `NN_short.md` files are design notes: question,
method, and risks for one experiment. `journal/ideas/` holds one
file per follow-up. The Ideas table summarizes those files and
their status. A promoted idea leaves Ideas and becomes a Backlog
row. A `## Results` section
(`### Report overview`, `### Checks`, `### Metrics`) is added after
evaluate/audit — it is not in the empty shell.
